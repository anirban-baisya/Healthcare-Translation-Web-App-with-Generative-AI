# Healthcare Translation Web App with Generative AI

A web application that provides translations for healthcare content using generative AI to assist with multilingual communication in clinical and patient-facing contexts.

Deployed URL: https://healthcare-translation-web-app-with-nine.vercel.app/

## Features
- Translate medical text between multiple languages
- Context-aware translations tailored to healthcare terminology
- Simple and accessible UI for clinicians and patients

## Technologies
- Frontend: React / Next.js (if applicable)
- Backend: Node.js / API routes
- AI: Generative models for translation

## Local setup
1. Clone the repository:

   ```bash
   git clone https://github.com/anirban-baisya/Healthcare-Translation-Web-App-with-Generative-AI.git
   cd Healthcare-Translation-Web-App-with-Generative-AI
   ```

2. Install dependencies:

   ```bash
   npm install
   # or
   yarn
   ```

3. Configure environment variables (copy .env.example to .env and set keys).

4. Run the development server:

   ```bash
   npm run dev
   # or
   yarn dev
   ```

## Usage
Open the app in your browser at http://localhost:3000 and use the translation interface or visit the deployed site: https://healthcare-translation-web-app-with-nine.vercel.app/
